# ISM Prayer Network

Design and build a world-class, ultra-modern, fully responsive web platform inspired by pn.voche.eu (ISM Ministers Prayer Network).

The new platform must retain ALL existing features and workflows, including:

User registration and login

Prayer request submission and viewing

Prayer groups (creation, joining, management)

Prayer room (live or scheduled sessions)

Prayer points (categorised)

Testimony submission and display

Multilingual support

Admin dashboard

Contact system

Now elevate it to a premium global SaaS-level design with:

Modern minimalist UI

Soft-glass card components

Micro-animations and smooth transitions

Fully responsive mobile-first layout

Dark and light mode toggle

Real-time elements where appropriate

Global interactive prayer map

Role-based user dashboard

Filterable prayer requests

Private and public prayer groups

Video testimony capability

Notification system

Optimized performance and SEO-ready structure

The design must feel global, spiritual, elegant, and technologically advanced.
It must be scalable and modular, with clean reusable components.

Include:

Landing page

Authenticated dashboard

Admin dashboard

All user flows fully functional

Clean backend structure ready for expansion

Make it visually stunning, smooth, and intuitive.
